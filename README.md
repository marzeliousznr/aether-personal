## features

- **farming qol** — auto farming, pest destroyer, auto pest exchange, auto spray, auto loadouts, auto greenhouse, auto composter
- **visual** — nick hider, purse spoofer, sawdust spoofer
- **failsafes** — BPS, ghost block, dirt, rotation, inventory detection
- **pathfinding** — A* walk, fly, and etherwarp navigation
- **discord** — remote control via Discord bot (opt-in)

## how to install

1. install [fabric for 26.1.2](https://fabricmc.net/use/installer/).
2. install [fabric API](https://modrinth.com/mod/fabric-api/versions?g=26.1.2) & [fabric language kotlin](https://modrinth.com/mod/fabric-language-kotlin).
3. download the latest jar from the [releases page](https://github.com/marzeliousznr/aether-personal/releases).
4. put the jar files into `.minecraft/mods`.
5. launch minecraft (make sure you're on the fabric profile).

> `/aether` opens the GUI.

## updating

this app never updates itself. run `git fetch origin` and review the diff, or download a release manually.
